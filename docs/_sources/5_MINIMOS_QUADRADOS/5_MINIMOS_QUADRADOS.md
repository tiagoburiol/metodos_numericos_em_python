# 5. Ajuste por Mínimos Quadrados

Quando os dados experimentais contêm ruído ou erros de medição, não é adequado interpolar — é preferível encontrar uma curva que represente a tendência geral dos dados minimizando os desvios. O método dos mínimos quadrados é a ferramenta padrão para esse tipo de ajuste.

```{rubric} Objetivos de aprendizagem
```

- Ajustar uma reta ou polinômio a dados pelo critério dos mínimos quadrados
- Resolver o sistema normal para obter os coeficientes do ajuste
- Aplicar linearizações para ajustar modelos não lineares
- Avaliar a qualidade do ajuste por meio de resíduos e coeficiente de determinação
