# 4. Interpolação Polinomial

Dado um conjunto de pontos $(x_i, y_i)$, a interpolação polinomial consiste em encontrar um polinômio que passe exatamente por todos esses pontos. É amplamente utilizada para reconstruir funções a partir de dados discretos e para aproximar valores entre pontos conhecidos.

```{rubric} Objetivos de aprendizagem
```

- Construir o polinômio interpolador de Lagrange
- Aplicar a forma de Newton com diferenças divididas
- Estimar e controlar o erro de interpolação polinomial
- Identificar situações em que a interpolação de alto grau é inadequada
