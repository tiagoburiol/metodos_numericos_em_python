# 2. Zeros de Funções

Determinar os zeros de uma função.ou seja, os valores de $x$ para os quais $f(x) = 0$, é um dos problemas mais recorrentes em ciências e engenharia. Em geral, a solução analítica não existe ou é de difícil obtenção, tornando os métodos numéricos indispen sáveis.

```{rubric} Objetivos de aprendizagem
```

- Localizar intervalos que contêm raízes de funções contínuas
- Aplicar métodos de refinamento iterativo: bisseção, ponto fixo, Newton-Raphson e secantes
- Analisar convergência, taxa de convergência e critérios de parada
- Calcular raízes de polinômios com métodos específicos
- Resolver problemas aplicados de engenharia e ciências
