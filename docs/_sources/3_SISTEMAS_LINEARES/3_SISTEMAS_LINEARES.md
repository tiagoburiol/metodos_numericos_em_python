# 3. Sistemas Lineares

Sistemas de equações lineares surgem naturalmente na modelagem de problemas físicos, estruturais e computacionais. A resolução eficiente de sistemas $Ax = b$ é uma das tarefas centrais da computação científica.

```{rubric} Objetivos de aprendizagem
```

- Representar sistemas lineares na forma matricial
- Aplicar eliminação gaussiana e escalonamento
- Utilizar decomposição LU para resolver múltiplos sistemas com a mesma matriz
- Calcular matrizes inversas pelo método de Gauss-Jordan
- Aplicar métodos iterativos de Jacobi e Gauss-Seidel
